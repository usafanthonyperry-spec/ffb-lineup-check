Public usage counter

After the first successful public checker run in a browser, the checker sends one anonymous counter hit. No league names, players, Sleeper IDs, passwords, or lineup data are sent. A local browser flag prevents repeat runs from counting again.

How updates work

Each time you run the Shortcut, it shows the latest available FFB version. Compare that number with the version shown at the top of your checker results. If your installed version is lower, return here and reinstall the checker.

Use it

Tap 🏈 Fantasy Lineup Check. The report shows every league, including lineup swaps, FLEX/SFLEX moves, and Spot Starts.

Red = lineup changes needed. Yellow = lineup is set, but Spot Starts are available. Green = no lineup or Spot Starts changes needed.

The summary counts use those same colors, and fully optimized green leagues are shown as compact cards so the red and yellow items stand out first.

The compact version/status area stays visible while you scroll. When the Shortcut passes ffb_latest, it also shows whether your installed checker is current or has an update available. On mixed reports, 🙈 Hide Optimized lives in that sticky area, temporarily hides the green cards, and remembers your last Hide/Show choice for future runs. If every league is clean, the summary says ✅ All leagues optimized.

Use 📋 Copy Summary for a text version, 📤 Share Results for the full PNG, or the built-in Suggest / Report Bug buttons to send feedback.
